## More specific corrections

The v0.2 document did allow reimplementations as research leads; the problem was that its release gates still made
exhaustive executable verification look like a prerequisite. Here, provisional source-backed adoption is an explicit
route.

The importer is a scope choice, not a trivial checkbox. First support one selected DOS edition. Do not promise all
ports, translations, graphics modes or repacks.

M1a answers "does the engine execute its rules?" M1b answers "does this subset behave like the chosen KB reference?"
Neither a four-case smoke suite nor a source code match establishes that the whole campaign is enjoyable or historically
exact.
